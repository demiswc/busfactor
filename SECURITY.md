# Security

busfactor holds sensitive information about people's lives, so security reports are very welcome.

**Please do not open a public issue for a vulnerability.** Email **security@busfactor.co.uk** with details and steps to reproduce.
You will get a reply within a few days. Please give reasonable time for a fix before publishing.

In scope: the code in this repository and the hosted service at busfactor.co.uk.
Out of scope: denial of service by traffic volume, reports from automated scanners without a demonstrated issue.
